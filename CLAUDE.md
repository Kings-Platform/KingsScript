# KingsScript — instruções pra IA

- **Como escrever script** (estrutura, regras, testes): [CONTRIBUTING.md](CONTRIBUTING.md). Seguir sempre.
- **Uso, comandos e contrato das camadas:** [README.md](README.md).
- **Decisões e fases:** `docs/`, local e fora do git — o repo é feito pra poder ser público, e esses docs citam contexto privado. Se a pasta existir, `docs/Roadmap.md` é o ponto de partida.

## O que vale só pra IA

- Docs de decisão em `docs/` são em português; todo o resto do repo é em inglês.
- Testar sempre com `HOME` temporário (ver CONTRIBUTING) — nunca rodar install/uninstall no `HOME` real.
- A IA faz os commits; o Gui revisa no GitHub Desktop e faz o push.
